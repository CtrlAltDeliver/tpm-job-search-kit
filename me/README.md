# me/

Put here:

- **Your resume** — a PDF whose filename contains `Resume` (e.g.
  `Jane Doe_TPM_Resume.pdf`). The routines read the *newest* matching PDF, so you
  can keep old versions around.
- **`goals.md`** — a short file naming what you're optimizing for (target role,
  target companies/industries, location, comp floor, anything you want the
  routines to weigh). `/apply` reads this to sanity-check that picks ladder up to
  what you actually want.

Nothing else is required. The richer these two files, the better the scoring.
