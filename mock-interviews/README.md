# mock-interviews/

Feedback from past mock interview rounds — one file per session (any format;
`.md` or `.docx`). `/interview-prep` reads every file here at the start of a
round so it can:

- name your **recurring weak spots** live ("you're still leaning thin on
  metrics"),
- notice when you **repeat** a pattern, and
- notice when you've **improved** since last time.

You don't create these by hand — `/interview-prep` and `/drill` produce the
feedback. This folder is what makes the coaching get better across sessions
instead of starting cold every time. Just leave the feedback files here.
